# Instrucciones del proyecto — Obsidian Vault (equipo SFMC/LFC)

Este repositorio es un vault de Obsidian de uso **interno** del equipo de Salesforce Marketing Cloud (SFMC/LFC). El contenido real vive dentro de la carpeta `Gera/`.

## Regla obligatoria de confidencialidad

Antes de leer, escribir, resumir o publicar (Artifact, mensaje, commit, push) cualquier contenido de este vault, sigue siempre lo definido en:

**`Gera/00. Sistema/Reglas/Reglas de Confidencialidad y Uso del Vault.md`**

Resumen — aplica a **cualquier modelo o asistente de IA** que trabaje con este repositorio, no solo a Claude:

1. **No** escribir el nombre real de la empresa dueña del negocio ni el de agencias/aliados/proveedores reales. La convención vigente es usar **"El Grupo"** (empresa) y **"La agencia"** (agencia saliente) — nunca los nombres reales. Excepción explícita: URLs, dominios y direcciones de correo reales no se tocan cuando son necesarios para que un enlace siga funcionando.
2. **No** incluir información de clientes/huéspedes reales, credenciales, tokens, cifras financieras no públicas, ni exports de datos reales — usar siempre datos de prueba/dummy.
3. Ante **duda razonable** de que una consulta, transcripción pegada, resultado de búsqueda o contenido a publicar contiene algo cubierto por las reglas 1-2: **no asumir que está bien**. Insertar una alerta explícita antes de continuar (ej. `⚠️ Posible información sensible detectada: ...`) y confirmar con el usuario antes de guardar o publicar.
4. Si se detecta una violación ya existente en el vault: señalarla con ubicación exacta (archivo y línea), **no** corregirla ni eliminarla unilateralmente, y no reproducirla en ningún resumen/artifact/mensaje mientras no se resuelva.

Lee la nota completa antes de operar sobre este repositorio — este archivo es solo el resumen de referencia rápida.
