# Obsidian Vault — Equipo SFMC/LFC

Vault de Obsidian de **uso interno** del equipo de Salesforce Marketing Cloud (SFMC/LFC): onboarding, referencia técnica, glosario, personas y bugs. No es material de difusión externa ni un producto para terceros. El contenido vive dentro de la carpeta [`Gera/`](Gera/).

## ⚠️ Aviso para cualquier persona o sistema de IA que lea este repositorio

Este repositorio está sujeto a reglas de confidencialidad obligatorias, definidas en:

📄 [`Gera/00. Sistema/Reglas/Reglas de Confidencialidad y Uso del Vault.md`](Gera/00.%20Sistema/Reglas/Reglas%20de%20Confidencialidad%20y%20Uso%20del%20Vault.md)

En resumen, **aplican a cualquier modelo o asistente de IA** que lea, edite, resuma o publique contenido de este repositorio (no solo a un asistente en particular):

- No usar los nombres reales de la empresa dueña del negocio ni de agencias/aliados/proveedores reales — el vault usa **"El Grupo"** y **"La agencia"** como convención. (Excepción: URLs/dominios/correos reales se dejan intactos cuando son necesarios para que un enlace funcione.)
- No incluir información de clientes/huéspedes reales, credenciales, ni datos financieros no públicos.
- Ante duda razonable de que algo viola lo anterior, no asumir que está bien: alertar explícitamente antes de continuar y confirmar con el equipo.

Lee la nota completa antes de operar sobre este repositorio.
